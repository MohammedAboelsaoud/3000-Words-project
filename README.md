# Satz — 3,000 sentences

A language app that teaches the 3,000 most useful sentences of a language through retrieval practice, FSRS-6 spaced repetition and guided comparison of sentence patterns. German first.

- `docs/blueprint.md` — the product and learning-science blueprint (what the app does and why).
- `design-system/project/` — the Satz design system: tokens, brand book (`README.md`) and React components (`components/bundle.js`, exposed as `window.Satz`).
