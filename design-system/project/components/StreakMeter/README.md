# StreakMeter

Days practised, the two streak freezes, and this week as dots: practised (filled), covered by a freeze (dashed), missed (sunken), today (ring).

**Provide:** `days`, `freezes` (0–2), `week` (seven states, Monday first).

- A day counts at 5 minutes or today's due reviews, whichever comes first.
- Freezes are free and earned back by an extra session within 72 hours. Never sell a streak repair.
- No leaderboards.
