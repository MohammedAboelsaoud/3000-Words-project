# BandRoadmap

The path: four bands (Survival, Foundations, Everyday life, Threshold) across 3,000 sentences, with the eight checkpoints (100, 300, 600, 1,000, 1,500, 2,000, 2,500, 3,000) as ticks. Passed checkpoints fill in ink.

**Provide:** `sentences` (how many the learner has started).

- The honest ceiling is "a vocabulary and pattern foundation toward A2/B1". Never label the end "B1" or "fluent".
- Celebrate each checkpoint, then show the next target straight away.
