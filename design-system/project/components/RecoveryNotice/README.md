# RecoveryNotice

Shown instead of the home screen after a gap. It explains the plan and gives the date the learner will be back on track — never the size of the backlog.

**Provide:** `date` ("Thursday"), `children` (the StartButton for the recovery session).

- Never show "847 due". Cap the recovery day at 1.5× the budget.
- The first session back is short and is recognised as a win.
