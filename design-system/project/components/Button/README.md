# Button

Ordinary actions inside a session: Check, Continue, Show answer. `quiet` is the default; `primary` is for the single next step on a screen; `text` for low-weight escapes ("Skip for today").

**Provide:** `children` (a verb, sentence case, no full stop), `onClick`, `variant`.

- One `primary` per screen. The Start button is not a Button.
- Labels are verbs the learner does: "Check", not "Submit answer".
