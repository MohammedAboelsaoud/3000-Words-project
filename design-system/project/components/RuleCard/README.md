# RuleCard

The one-line rule, shown only after the learner has compared a family. States the frame in German and the rule in the gloss language.

**Provide:** `frame` ("Ich hätte gern ___") and `rule` (one line, no jargon the learner hasn't met).

- One line. If it needs two, the family is too big.
- Never shown before the comparison task.
