# AlignmentStrip

The L1/L2 strip: a literal gloss under each German word, marking what has no counterpart in the learner's language (dotted underline, "—") and what moves (→).

**Provide:** `tokens` (`{de, gloss, mark}` with `mark` one of `slot`, `none`, `moves`), `glossDir`/`glossLang` for Arabic, and a one-line `note` naming the difference.

- English strips expose cognates; Arabic strips show where German adds or moves pieces. Arabic glosses need native review.
- One `note`, one difference. Don't annotate every cell.
