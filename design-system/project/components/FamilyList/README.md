# FamilyList

A new pattern family of 3–5 sentences sharing one frame and anchor word, shown together once. The learner first taps what stays the same; then `revealed` marks the varying slot and names the frame.

**Provide:** `sentences` (slot in brackets), `frame` (e.g. "Ich hätte gern ___"), `revealed`.

- Ask for similarities before differences. Hunting for differences alone hurts learning.
- The rule appears after this, in a RuleCard — never before.
