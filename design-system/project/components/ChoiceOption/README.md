# ChoiceOption

One answer in a pick-1-of-3 comprehension task (audio → meaning). After checking, the chosen option shows `correct` or `wrong`, each with a word as well as a colour.

**Provide:** `children` (the translation), `state`, `dir`/`lang` for Arabic options, `onClick`.

- Three options, never four. Distractors come from the same pattern family.
- Show the right answer and play the audio again after every attempt, right or wrong.
