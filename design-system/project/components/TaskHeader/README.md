# TaskHeader

Every exercise screen opens with a one-line instruction and a one-line reason. The reason collapses after the learner has seen a format a few times.

**Provide:** `instruction` (imperative, one line), `reason` (why this format helps), `showReason` (false after ~3 uses of the format), `progress` (0–1 of today's minutes, not items).

- Progress is time, never "12 / 80 cards".
